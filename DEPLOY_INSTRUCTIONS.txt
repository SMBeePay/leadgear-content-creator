⏱️  TIME REQUIRED: ~10-15 minutes total

════════════════════════════════════════════════════════════════
STEP 1: DEPLOY BACKEND TO RAILWAY (5 minutes)
════════════════════════════════════════════════════════════════

1. Open https://railway.app/new

2. Sign in with your GitHub account

3. Click "Deploy from GitHub repo"

4. Select your repository: "leadgear-content-creator"

5. Railway will detect the Dockerfile

6. Click on the deployed service, then "Variables" tab

7. Add these environment variables:

   JWT_SECRET=<run this command: openssl rand -hex 32>
   FRONTEND_URL=https://will-update-after-vercel-deploy.com
   DATABASE_URL=sqlite:///./data/leadgear.db

8. Click "Settings" tab → Copy the "Public Domain" URL
   Example: https://leadgear-backend-production.up.railway.app

   ⭐ SAVE THIS URL - YOU'LL NEED IT FOR VERCEL!

════════════════════════════════════════════════════════════════
STEP 2: DEPLOY FRONTEND TO VERCEL (5 minutes)
════════════════════════════════════════════════════════════════

OPTION A: Using Vercel CLI (Faster)
────────────────────────────────────
1. Install Vercel CLI:
   npm i -g vercel

2. Login:
   vercel login

3. Deploy:
   cd frontend
   vercel

4. Follow prompts:
   - Set up and deploy? YES
   - Which scope? [Your account]
   - Link to existing project? NO
   - What's your project's name? leadgear-content-creator
   - In which directory is your code located? ./
   - Want to override the settings? NO

5. Add environment variable:
   vercel env add VITE_API_URL

   When prompted, paste your Railway URL:
   https://your-backend.up.railway.app

6. Deploy to production:
   vercel --prod

────────────────────────────────────
OPTION B: Using Vercel Dashboard
────────────────────────────────────
1. Open https://vercel.com/new

2. Import your Git repository

3. Configure project:
   Framework Preset: Vite
   Root Directory: frontend
   Build Command: npm run build
   Output Directory: dist
   Install Command: npm install

4. Add Environment Variable:
   Name: VITE_API_URL
   Value: [Your Railway URL from Step 1]

5. Click "Deploy"

6. Wait ~2 minutes for deployment

7. Copy your Vercel URL when ready
   Example: https://leadgear-content-creator.vercel.app

════════════════════════════════════════════════════════════════
STEP 3: UPDATE BACKEND CORS (2 minutes)
════════════════════════════════════════════════════════════════

1. Go back to Railway dashboard

2. Click on your backend service

3. Click "Variables" tab

4. UPDATE the FRONTEND_URL variable:
   FRONTEND_URL=https://your-actual-vercel-url.vercel.app

5. Railway will automatically redeploy (~1 minute)

════════════════════════════════════════════════════════════════
STEP 4: TEST YOUR DEPLOYMENT! (2 minutes)
════════════════════════════════════════════════════════════════

1. Open your Vercel URL in a browser

2. Click "Register" and create a test account

3. Login with your credentials

4. Create a test project:
   - Client Name: "Test HVAC Company"
   - Website: https://test.com
   - Industry: HVAC
   - Click Create

5. If the project appears in your list = SUCCESS! 🎉

════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════

❌ "Network Error" when logging in
   → Check VITE_API_URL is set correctly in Vercel
   → Verify Railway backend is running (green in dashboard)

❌ "CORS Error" in browser console
   → Check FRONTEND_URL in Railway matches your Vercel URL exactly
   → Make sure both URLs use https:// (not http://)

❌ Vercel build fails
   → Check deployment logs in Vercel dashboard
   → Try building locally first: cd frontend && npm run build

❌ Railway deployment fails
   → Check deployment logs in Railway dashboard
   → Verify Dockerfile exists in backend directory
